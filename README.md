# دستیار حقوقی هوشمند کارگر

نسخهٔ دموی وب‌اپ «دستیار حقوقی هوشمند کارگر» — یک دستیار حقوقی برای کارگران که با یک گفتگوی هدایت‌شده یا فرم مستقیم، مطالبات قانونی (سنوات، عیدی، مرخصی، اضافه‌کاری، حقوق معوق) را بر پایهٔ قانون کار محاسبه کرده و یک پیش‌نویس دادخواست رسمی برای ادارهٔ کار تولید می‌کند.

این یک **نسخهٔ دموی کاملاً سمت کلاینت** است — بدون بک‌اند، بدون دیتابیس، بدون احراز هویت واقعی. تمام state (ورود با شماره موبایل، گفتگو، محاسبات، سند نهایی) در حافظهٔ مرورگر مدیریت می‌شود و با رفرش صفحه از بین می‌رود.

## اجرا

```bash
npm install
npm run dev       # سرور توسعه
npm run build     # بیلد production در dist/
npm run preview   # پیش‌نمایش بیلد production
npm run lint      # oxlint
```

## تکنولوژی

- React 19 + TypeScript + Vite
- بدون کتابخانهٔ CSS خارجی — استایل‌ها inline + یک stylesheet سراسری (`src/index.css`) برای انیمیشن‌ها، سایه‌ها و ریسپانسیو
- فونت وزیرمتن به‌صورت self-host از طریق `@fontsource/vazirmatn`

## ساختار

```
src/
  state/store.tsx      state مرکزی برنامه (Context + hooks) — همهٔ صفحات و اکشن‌ها از اینجا می‌آیند
  lib/                  دادهٔ ثابت (سوالات گفتگو، FAQ، مواد قانونی) + منطق محاسبهٔ مطالبات
  components/           هر صفحه/بخش UI یک کامپوننت جداست (Dashboard, ChatPanel, FormPanel, ResultPage, ...)
  types.ts              تایپ‌های مشترک
```

## ورود به دمو

صفحهٔ ورود با شمارهٔ موبایل کار می‌کند اما واقعی نیست:
- هر شماره‌ای با فرمت صحیح (`09xxxxxxxxx`) بپذیرید، کد تأیید دمو **۱۲۳۴** است.
- یا از دکمهٔ «ورود سریع برای نمایش (دمو)» برای رد شدن از کل فرآیند استفاده کنید.

## نکات دمو

- بارگذاری مدارک/مستندات در این نسخه غیرفعال است (فقط نمایشی).
- دکمهٔ «پر کردن سریع با دادهٔ نمونه» در تب گفتگو، کل مسیر را با دادهٔ آزمایشی پر می‌کند.
- ریسپانسیو کامل: زیر ۹۸۰px، سایدبار راست به یک drawer کشویی تبدیل می‌شود.
